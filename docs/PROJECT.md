# Ingenium — Project

## What Ingenium is

Ingenium is a long-term personal project to build, incrementally, a modular platform capable of coordinating intelligent agents, local AI models, software integrations, physical devices, computer vision, audio, automation and, eventually, robotics.

The goal is not simply to build a local chatbot. Ingenium should become a personal intelligence and automation infrastructure that can grow with new modules and capabilities without being rewritten at each expansion.

## Identity

*Ingenium* is Latin, associated with natural capacity, talent, ingenuity, innate quality and genius. It is also historically related to the roots of words such as *engineer*. The name matches the purpose of the project: building capabilities through engineering.

### Naming convention for major components

Important future modules may receive names from Latin, Ancient Greek, Hebrew or other appropriate historical languages. A name is not chosen just because it sounds good. Each name must have:

- a real origin;
- a real meaning;
- a conceptual relationship with the module's responsibility.

Names are chosen when modules actually appear, never in advance.

## Long-term vision

Ingenium may eventually include:

- local LLM execution;
- multiple specialized agents;
- persistent memory;
- computer vision, image recognition and cameras;
- audio processing, speech recognition and speech synthesis;
- music agents (composition and accompaniment);
- automations and API integrations;
- Arduino, ESP32, sensors, relays, motors and servos;
- device control and home automation;
- robots;
- multiple machines running different workloads.

One long-term idea is musical agents that are not just scripts, but eventually physical or robotic entities able to accompany music like a band.

All of this is long-term vision only. The project starts with very small experiments.

## Goals

- Build a system that grows by adding capabilities, not by rewriting its core.
- Develop deep engineering understanding while building it.
- Keep the project resumable at any stable point.

## Scope

In scope now: Genesis, the first phase (see [ROADMAP.md](ROADMAP.md)).

Out of scope now: LLMs, agent frameworks, hardware, dedicated servers and heavy infrastructure. These become relevant only when a real need appears.
